# RQ1 论文草稿：宽带中国试点与老年健康平均效应

## 一、模型方法

### 1. 识别策略

本文利用“宽带中国”试点在城市层面交错实施的时间差异，使用 Callaway & Sant'Anna (2021) 提出的交错双重差分估计量（CS-DID）识别试点对老年健康的平均处理效应（ATT）。

将城市按其首次成为试点的时期划分为处理队列 `g ∈ {3, 4}`，即 2015 年（wave 3）和 2018 年（wave 4）首次试点的城市；从未试点城市作为纯净对照组（`g = 0`）。对每一个队列-时期组合，估计：

```text
ATT(g, t) = E[Y_t(g) - Y_t(0) | G_i = g]
```

其中 `Y_t(g)` 为队列 `g` 在时期 `t` 的潜在结果，`Y_t(0)` 为从未处理状态下的潜在结果。总体平均处理效应通过 `aggte(type = "simple")` 对后处理期进行加权平均得到。

### 2. 估计细节

- 估计方法：双重稳健（doubly robust, `est_method = "dr"`），同时使用倾向得分加权和结果回归。
- 对照组：从未处理城市（`control_group = "nevertreated"`）。
- 基准期：统一基准期（`base_period = "universal"`）。
- 面板结构：允许非平衡面板（`allow_unbalanced_panel = TRUE`）。
- 聚类：标准误在城市层面聚类（116 个城市），`clustervars = "city_code"`。
- 主窗口：2011-2018，排除 2020 疫情波；全样本 2011-2020 作为稳健性。
- 多重检验：对 5 个结果变量报告 Benjamini-Hochberg FDR 校正后的 q 值。
- 事件研究：动态 ATT 使用同时置信带（simultaneous confidence bands），以 `e = -1` 为参考期。
- 稳健性：城市层面聚类 bootstrap（999 次）复核 `func_cap` 的 p 值。

### 3. 主回归协变量

主估计控制以下基线（2011 年）协变量：

```text
X = {age_base, gender_base, rural_base, edu_base}
```

扩展控制的稳健性估计再加入：

```text
X_ext = X ∪ {marry_base, hhcperc_base, gdp_pc_log_base}
```

其中 `gdp_pc_log_base` 取 2011 年城市人均 GDP 的对数，避免使用可能受政策影响的逐年宏观变量。

## 二、变量定义

| 变量 | 定义 | 说明 |
| --- | --- | --- |
| `gvar` | 首次处理波次 | `3`=2015 试点；`4`=2018 试点；`0`=从未试点 |
| `treat` | 当期是否已处理 | `treat = 1(wave >= gvar)` |
| `func_cap` | 功能能力指数 | `1 - (ADL + IADL) / 11`，越高越好 |
| `bhci` | 综合健康能力指数 | 功能、心理、感知三维等权 |
| `psych_cap` | 心理健康能力 | 单维指数 |
| `srh_cap` | 自评健康能力 | 单维指数 |
| `che` | 灾难性卫生支出 | 年自付医疗支出/家庭人均消费 >= 40%，二元变量 |
| `age_base` | 基线年龄 | 连续 |
| `gender_base` | 基线性别 | 0/1 |
| `rural_base` | 基线农村 | 0/1 |
| `edu_base` | 基线教育 | 分类 |
| `marry_base` | 基线婚姻 | 0/1 |
| `hhcperc_base` | 基线家庭人均消费 | 连续 |
| `gdp_pc_log_base` | 基线城市人均 GDP 对数 | 2011 年城市值 |

## 三、样本口径

分析样本满足以下条件：

- 2011 年基线年龄 >= 60；
- 2011 年至少确诊一种慢性病；
- 城市可匹配且 `city_code` 非缺失；
- `BHCI` 完整；
- 排除未匹配的自治州、盟、地区。

| 样本 | 基线人数 | 人-年观测 | 城市数 |
| --- | --- | --- | --- |
| 主窗口 2011-2018 | 4,863 | 15,883 | 116 |
| 全样本 2011-2020 | 5,110 | 18,335 | 116 |

116 个城市中，46 个为试点城市（第一批 21 个、第二批 15 个、第三批 10 个），70 个为从未试点城市。

## 六、文字段落（可直接使用）

### 6.1 结果描述

表 RQ1-A 报告了 2011-2018 年窗口内宽带中国试点对老年健康能力的平均处理效应。结果显示，功能能力指数显著提高 0.0257（SE = 0.00866，p = 0.003，FDR q = 0.015），约相当于 0.28 个 ADL/IADL 项目；综合健康能力指数、心理健康能力、自评健康能力和灾难性卫生支出均无显著变化。这表明政策效应集中于功能维度，而非综合健康水平或经济负担。

### 6.2 动态效应

事件研究结果显示，功能能力的改善在处理当期出现：`e = 0` 的 ATT 为 0.0247，95% 同时置信带为 [0.0062, 0.0432]，不包含 0；`e = 1` 的 ATT 为 0.0278，置信带包含 0。处理前各期点的置信带均包含 0，支持平行趋势假设。由于主窗口止于 2018 年，该结果应理解为疫情前短期到中期效应。

### 6.3 稳健性

分队列估计显示，2015 年试点城市和 2018 年试点城市的功能效应均为正，效应并非由某一批次城市单独驱动。加入婚姻状况、基期家庭人均消费和基期城市人均 GDP 等扩展控制后，功能能力效应为 0.0281（p = 0.004，FDR q = 0.019），结论不变。纳入 2020 年全样本后，效应方向一致但精度下降（ATT = 0.0199，p = 0.025，FDR q = 0.124），这与此前讨论的疫情波数据质量与失访问题一致。城市层面聚类 bootstrap（999 次）给出 bootstrap t 检验 p 值为 0.007，进一步支持主结论。

### 6.4 结论与限制

综上，RQ1 的结论是：在疫情前窗口内，宽带中国试点显著改善了老年功能健康，但未显著改变综合健康指数、自评健康、心理健康或灾难性卫生支出。需要说明，试点城市在基期经济发展水平和农村占比上存在明显差异，城市选择仍是主要的识别威胁；扩展控制虽然未改变结论，但不能完全替代随机化或更严格的匹配设计。后续稳健性应继续补充基于失访的 IPW、Lee Bounds 和更细化的城市匹配分析。
